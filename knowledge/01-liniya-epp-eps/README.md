## Электропитание линии EPP, если всё на электричестве (оценка 2026-11-13)
Оценка инженерная, без КП. Уточнить по паспортам оборудования поставщика.
- Основной потребитель — электрический парогенератор: около 0,75–0,8 кВт·ч на 1 кг пара. Для EPP нужен пар 3–4,5 бар, это заметно больше, чем для EPS.
- Нагрузка по составу линии: парогенератор 400–1000 кВт; формовочные машины по 15–30 кВт каждая; компрессор 30–55 кВт; вакуумная система 15–30 кВт; камера сушки/выдержки изделий 30–100 кВт; градирня и насосы 10–20 кВт; бункеры и транспорт 10–20 кВт.
- Итог: 1 машина ≈ 0,4–0,6 МВт; 2–3 машины ≈ 0,8–1,3 МВт; 4 и больше ≈ 1,5–2 МВт.
- Подключение для 2–3 машин: 1–1,5 МВт, своя ТП 10/0,4 кВ 1250–1600 кВА, II категория надёжности.
- Как снизить мощность подключения: паровой аккумулятор — уменьшает котёл в 1,5–2 раза; газовый котёл на пар — минус 60–75 % электрической мощности.
- Удельный расход: примерно 3–6 кВт·ч на 1 кг готового EPP.
