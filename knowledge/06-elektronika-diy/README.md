# Электроника и DIY-наборы (микросхемы, датчики, детали) + программирование через ИИ-агента

> Статус: идея, проработка
> Последнее обновление: 2026-11-15

## Суть идеи
Продавать микросхемы, датчики, модули и детали для сборки полезных устройств
(быт, работа, производство), а прошивку/программирование делать через ИИ-агента:
клиент описывает словами, что хочет — агент пишет и заливает код.

## Ключевая мысль (отличие от обычного магазина радиодеталей)
Комплектующие продают все (AliExpress, Chip&Dip, ЧиД, Амперка, Ozon). Продавать
нужно не детали, а **готовый результат**: «набор + ИИ-прошивка под твою задачу».

## Варианты продукта
1. **Готовые наборы под задачу** — «датчик протечки», «контроль температуры в
   гараже/теплице», «умный счётчик», «сигнализация на ворота». Детали + корпус +
   инструкция + прошивка от ИИ.
2. **Промышленные наборы (синергия с заводом)** — мониторинг станков, датчики
   температуры/давления/вибрации, счётчик продукции, Telegram-уведомления.
   Прямо пересекается с «слежением за линией EPP/EPS» (направление 01) —
   можно сначала сделать для себя, потом продавать как кейс.
3. **Конструктор «собери сам»** — база (ESP32) + модули на выбор, ИИ-агент
   генерирует код под выбранную комбинацию.

## Базовая платформа (предложение)
- Контроллер: ESP32 (Wi-Fi/Bluetooth, дёшево, огромная экосистема).
- Прошивка: ESPHome / Arduino; заливка через браузер (Web Serial) — без IDE у клиента.
- ИИ-агент: принимает описание задачи → выдаёт конфиг/код → проверка → прошивка.
- Корпуса: 3D-печать (синергия с направлением 04).
- Уведомления: Telegram-бот / Home Assistant.

## Открытые вопросы
- [ ] Кто клиент: частники-самоделкины, бытовые пользователи «под ключ» или предприятия?
- [ ] Свой склад деталей или дропшиппинг/закупка под заказ (Китай)?
- [ ] Где продавать: свой сайт, маркетплейсы (Ozon/WB), Telegram?
- [ ] Первые 3–5 наборов-«хитов» для старта.
- [ ] ИИ-агент: веб-сервис для клиента или внутренний инструмент (мы прошиваем сами)?
- [ ] Ответственность и безопасность: сеть 220 В, газ, замки — только проверенные схемы.
