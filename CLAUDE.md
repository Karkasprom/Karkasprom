# КАРКАС ПРОМ — контекст для Claude

Этот файл Claude читает в начале каждой сессии. Здесь собрано всё, что нужно знать,
чтобы не начинать с чистого листа.

## О компании
- КАРКАС ПРОМ — металлоконструкции, металлокаркасы и метизы.
- Сайт: `index.html` в корне репозитория (одностраничный сайт с каталогом и формой заявки).

## Правила для Claude
1. Перед ответом по любой теме прочитай `README.md` нужной папки в `knowledge/`.
2. После каждой сессии дописывай в README темы: что решили, что осталось открытым, дату.
3. Новые выгрузки переписок кладутся в `knowledge/_inbox/` — их нужно разобрать по темам.
4. Общение — на русском, коротко и по делу.
